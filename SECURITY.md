# Security Policy

Everflow Logistics takes the security of this website and customer information seriously.

## Reporting a security issue

If you believe you have found a security vulnerability affecting everflowdelivery.com, please report it privately to Everflow Logistics at Everflowlogistics947@gmail.com.

Please do not include customer personal information, passwords, access tokens, or other sensitive data in a public GitHub issue.

## Sensitive information

Secrets, credentials, API keys, private keys, and environment files must never be committed to this repository. Use protected environment variables or service-level secret storage for any future integrations that require credentials.

## Customer data

The public website repository must never contain customer quote submissions, customer addresses, medical information, payment information, or other customer records.
